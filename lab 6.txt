Lab 6: Patient Roster Analyzer (Lists and Tuples)

20 points. Due Sunday 11:55pm.
Scenario

You've calculated BMI for one patient at a time (Lab 1), handled multiple fields per patient (Lab 2), classified a single patient (Lab 3), and processed a batch of patients with a loop (Lab 4). This week you store that batch properly: as a list of patient records, instead of separate variables for each patient.

Each patient record is a tuple: (name, age, weight_lbs, height_in). A tuple is correct here because once a patient's intake data is recorded, it shouldn't change in this program, immutability enforces that.
What Your Program Must Do

    Build a list of patient tuples. Use this starter dataDownload starter data (you do not need to collect input for this lab):

python

patients = [
    ("Alvarez, Maria", 34, 148, 65),
    ("Chen, Wei", 52, 210, 70),
    ("Thompson, Derek", 29, 165, 68),
    ("Patel, Ananya", 45, 132, 62),
    ("Johnson, Marcus", 61, 195, 71),
]

    Write a function calculate_bmi(weight_lbs, height_in) that returns BMI using the formula:

BMI = (weight_lbs / (height_in ** 2)) * 703

This should reuse the same modular approach from Lab 5, not inline math in the middle of a loop.

    Process the full list and, for each patient, print their name and BMI, rounded to 1 decimal place.
    Compute and print, across the whole roster:
        Average BMI
        The name and BMI of the patient with the highest BMI
        The name and BMI of the patient with the lowest BMI
    Print the roster sorted by BMI, lowest to highest, with each line showing name and BMI.

Expected Output Shape

Alvarez, Maria: BMI 24.6
Chen, Wei: BMI 30.1
Thompson, Derek: BMI 25.1
Patel, Ananya: BMI 24.1
Johnson, Marcus: BMI 27.2

Average BMI: 26.2
Highest BMI: Chen, Wei (30.1)
Lowest BMI: Patel, Ananya (24.1)

Roster sorted by BMI:
Patel, Ananya: 24.1
Alvarez, Maria: 24.6
Thompson, Derek: 25.1
Johnson, Marcus: 27.2
Chen, Wei: 30.1

Your exact spacing can vary. The values must match.
Requirements

    calculate_bmi() must be a standalone function with a docstring, matching the style from Lab 5.
    Do not hardcode the highest/lowest/average values. Calculate them from the list.
    Use .sort() or sorted() for the final roster output, don't manually reorder the list by hand.
    Tuple unpacking (name, age, weight_lbs, height_in = patient) is required when pulling fields out of each record, don't index into the tuple with patient[0], patient[1], etc.

Watch Out For

    list.sort() sorts in place and returns None. If you're sorting a list of tuples by BMI and BMI isn't the first item in the tuple, you'll need a key= argument, see the Reference Sheet's Common Mistakes section if you're stuck here before asking in office hours.
    Rounding happens for display only. Don't round before using a value in another calculation (like the average), round at the print step.
